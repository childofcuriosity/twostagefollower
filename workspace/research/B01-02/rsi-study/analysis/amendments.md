# Implementation refinements and amendments

1. Initial downloads failed because httpx was absent from the training environment. Switched to standard-library urllib without changing global/training dependencies. Failed logs remain.
2. Loop proposal metrics follow the actual system source: frozen uses the base with LoRA disabled; other conditions use the updated model. Preserved frozen utility is a structural control, not evidence that its executor learned to preserve proposing.
3. String replication shares family ASTs, so hidden macros cannot be claimed semantically disjoint across splits under the new semantics. String selection uses complete length-3–8 semantic signatures to exclude identities/duplicates. Execution training excludes functions equivalent to fixed evaluations in that domain. This replicates execution semantics, not independent abstraction syntax.
4. The initial protocol did not require optimizer-state continuity. AdamW is rebuilt each round while model/LoRA parameters carry forward, consistently across conditions. Save each adapter and do not describe an uninterrupted optimizer trajectory.
5. Before viewing any new loop/causal-branch results, add gradient diagnostics for numeric shared/joint across three seeds and rounds 0–3. Fix three groups of four execution/proposal examples; proposal targets are frequency-optimal single macros from training support. Measure execution/proposal-NLL gradient angles only, not sampled-utility gradients or sufficient causal evidence. Parameters are not updated.
6. Before loop jobs start, refine shuffled replay to shuffle pairings only within equal-target-token-length buckets. Under identical sample indices, each step matches unshuffled auxiliary-token counts, rather than only matching pool totals. Save a new registration without overwriting earlier ones. Some targets may retain original pairings by chance; report the fraction.
7. After some 1.5B/3B robustness results but before loop inspection, add a post hoc coverage control. Original macros omit ends; manually replace brown=inc, inc, inc with ends, inc, inc while preserving macro count, chains, inputs, primitive-step counts, and budget. This is not model discovery of a new macro. Train three macro seeds and use the same prompt/budget grid. Refilter development/test training-equivalent functions under new semantics and record counts. Cross-world OOD scores are not single-factor capability comparisons. Proposal evaluation remains unchanged. This tests one missing primitive, not every distribution mismatch.
8. Stage A shows substantial changes in 3B length-three proposal frequency, while initial loop results show no degradation. Add post hoc quotas to test constrained stopping-length preference: three seeds for each model/base/flat/macro, same instruction prompt and T=1, forcing eight length-two and eight length-three candidates with the same support selector. Change only grammar-permitted lengths, retain all results, preserve the original primary setting, and do not retune quotas from results.
9. Initial round-one loop results show no proposer degradation, so updated-versus-base branches may not manipulate declining proposal quality. Their null differences cannot refute harm from degradation. Add separate post hoc stress branches from identical shared round-one learners, using the demonstrably degraded original numeric macro adapter externally. Preserve support, selector, training seeds, and 128 steps. Test both execution domains; strings also use the numeric proposer, transferring only primitive-sequence proposals. Keep primary branches unchanged. This tests an externally introduced degraded-source total effect, not spontaneous loop degradation.
10. Reorder only waiting schedulers to use idle GPUs: after numeric causal branches, run coverage and length before string branches, gradients, and legacy. No training is interrupted or parameters changed. Retain dispatch logs and queue-reorder.json.
